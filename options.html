Gemini Live Avatar

A draggable Gemini Live companion that sees the page you're on and talks with you. Click the toolbar button on any tab to bring it up; click it again (or ✕) to send it away.

Mode

Vertex AI connection

The extension talks to the Vertex AI Live API directly, as you. It needs a Google Cloud project with the Vertex AI API enabled and access to gemini-3.8-live, and the Google credentials below.

Gemini API connection

Create a key at aistudio.google.com/apikey. It's sent to the Gemini Live API only, and stored unencrypted in this Chrome profile's extension storage.

Google credentials

Used for Vertex AI and, if you set a memory folder, for Google Drive.

Only needed for Drive memories (below).

Paste either:
  • your ADC JSON, refreshed automatically: cat ~/.config/gcloud/application_default_credentials.json (from gcloud auth application-default login), or
  • a short-lived access token (about 1 hour): gcloud auth application-default print-access-token.
Stored unencrypted in this Chrome profile's extension storage.

Memories (Google Drive)

Give Gemini a Drive folder as its long-term memory. At the start of each conversation it reads the folder's Google Docs, Sheets, Slides, and text files, and it saves new memories to Gemini memories.md there. Leave empty to turn memories off.

Uses the Google credentials above, which need Drive access. Create them with: gcloud auth application-default login --scopes=openid,https://www.googleapis.com/auth/userinfo.email,https://www.googleapis.com/auth/cloud-platform,https://www.googleapis.com/auth/drive and bill the Drive API to a project of yours that has it turned on: gcloud auth application-default set-quota-project YOUR_PROJECT gcloud services enable drive.googleapis.com --project YOUR_PROJECT Then paste the new ADC JSON above.

Microphone

The avatar listens through your microphone. Chrome asks once for the extension; choose Allow while visiting the site.

Avatar

Leave empty for the default persona. Page-awareness and speaking rules are added automatically.

Page awareness

The avatar always gets the page's title, URL, text, and your text selection. It can also see screenshots of the visible part of the tab, taken when the page changes.

0 turns screenshots off.
